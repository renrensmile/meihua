# 梅花易数笔记写法

本站用于整理梅花易数的学习资料。先保存原始观察，再归纳理解；避免只留下结论而没有推演依据。

## 基础知识类笔记

用于记录八卦、五行、体用、互卦、变卦等基础概念。

```markdown
# 笔记标题

## 概念

用自己的话说明这个概念。

## 取象线索

列出相关的卦象、五行、人物、方位、物象等。

## 容易混淆的地方

写下常犯的错误与辨别方法。

## 练习

记录观察或联想练习。
```

## 起卦与案例复盘

事实记录与判断分开书写：

```markdown
# 案例标题

## 事情背景

只记录可确认的事实，必要时匿名化。

## 起卦信息

- 起卦时间：
- 起卦方法：
- 所问事项：

## 卦象记录

- 本卦：
- 互卦：
- 变卦：
- 体用：

## 推演依据

分别写明取象、五行关系、体用关系等依据。

## 后续与复盘

记录后续事实，并复盘哪些判断有依据、哪些属于牵强附会。
```

## 文件与栏目

- `docs/basics/`：阴阳、五行、八卦、六十四卦等基础体系。
- `docs/divination/`：起卦方法与练习记录。
- `docs/cases/`：完整案例与复盘。
- `docs/tools/`：辅助记忆与练习工具。

::: warning 注意
涉及他人隐私的案例要匿名处理。健康、法律、财务等现实重要事项，以专业意见与可靠事实为准；学习笔记不代替专业决策。
:::
