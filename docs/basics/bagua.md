# 八卦基础

八卦是梅花易数取象与判断的重要基础。学习时不只背诵名词，也在具体事物中练习观察象意。

## 八卦速览

| 卦 | 象 | 五行 | 常见取象方向 |
| --- | --- | --- | --- |
| 乾 | 天 | 金 | 刚健、首领、圆形、高处 |
| 坤 | 地 | 土 | 承载、母亲、方形、田地 |
| 震 | 雷 | 木 | 动、长男、足、突发 |
| 巽 | 风 | 木 | 入、长女、木、传播 |
| 坎 | 水 | 水 | 险、耳、流动、隐伏 |
| 离 | 火 | 火 | 明、目、文书、附着 |
| 艮 | 山 | 土 | 止、少男、门、阻隔 |
| 兑 | 泽 | 金 | 悦、少女、口、缺损 |

乾兑金

## 练习

每天选一个卦，从环境、人物、物品、动作中各找几个对应的象；再回看是否牵强，逐渐提高取象准确度。
