# 梅花覆射专用五行取象技巧

> 核心原则：**五行是大类筛选器，卦德、卦形定细节；先五行定材质大类，再八卦取形态功用** 五行优先级（射覆）：**五行→卦德→卦形→旺衰** 五行不单独断物，用来快速缩小候选范围，避免像上一局直接跳到电器（金不一定是电器，木不一定是花草）

## 一、五行基础类象（物质本体，射覆最常用）

### 木｜震☳、巽☴

**本性：曲直、生发、长条、纤维、有纹理、可弯折、草木**

1. 材质：草木、竹木、藤、纸张、棉麻、植物果实、纤维制品
2. 形态：细长、片状、枝叶、杆状、有纹路、可摇摆弯曲
3. 颜色：青、绿、浅碧、棕青
4. 动静：震木偏**动、直立、敲击有声、突发**；巽木偏**薄、软、穿透、随风、薄片**
5. 射覆重点区分

- 震木：主干、粗杆、春笋、活植物、敲击发声、直立向上
- 巽木：叶片、薄纸、织物、扇子、细绳、管道、轻薄可入之物

> 易错：木≠一定是活花草！干果、纸张、布料都是木五行。

### 火｜离☲

**本性：炎上、光明、中空、附丽、外实内虚、文采**

1. 材质：燃烧物、发光物、带外壳中空之物、文书字画、塑料（很多带离象）
2. 形态：中间空、外壳包裹内核、有花纹、艳丽、尖形
3. 颜色：红、紫、橙、花纹斑斓
4. 动静：发光、发热、看得见、需要依附别的东西才能存在

> 射覆重点：**中空是离第一特征！** 凡是中间空、外壳一层的东西优先考虑离：杯子、灯罩、圆环（镯子中空属离）。

### 土｜艮☶、坤☷

**本性：稼穑、承载、厚重、块状、收纳**

- 坤土：松散、大片、柔软、可容纳、扁平、多碎块、腹、袋子、泥土、布匹
- 艮土：坚硬、凸起、块状、停止、阻隔、石头、陶瓷、小山、疙瘩、把手 颜色：黄、棕、咖啡色、米白

> 射覆区分： 坤土：软土、布袋、软垫、可包容； 艮土：硬土、石块、陶瓷疙瘩、凸起、阻挡物。

### 金｜乾☰、兑☱

**本性：从革、坚硬、收敛、可雕琢**

- 乾金：**实心、浑圆、完整、厚重、贵重、整块硬实**（重点！乾大多实心）
- 兑金：**有缺口、开口、破损、口状、能发声、薄片金属** 颜色：白、银、金属色、浅金色

> 射覆大坑：乾金优先【实心硬圆】，圆环中空不属于乾，中空要归离！ 乾金：玉石、金属圆珠、硬实圆纽扣；兑金：小刀、金属开口器皿、铃铛。

### 水｜坎☵

**本性：润下、流动、隐伏、外虚内实、幽暗**

1. 材质：液体、含水之物、冰、软体、潮湿、黑色物质
2. 形态：中间实、外面包裹、弯曲、蜿蜒、凹陷、坑洞
3. 颜色：黑、深蓝、灰
4. 射覆重点：不一定是清水！含水的物品、软体、隐蔽在内的东西都属坎。

> 例：药丸、墨水、潮湿抹布、密封里面有水的物件。

## 二、五行取象 4 个核心技巧（射覆专用）

### 技巧 1：五行先定「材质大类」，不要直接定物品

拿到卦，第一步只用五行筛：

- 体卦木：优先草木 / 纤维类
- 体卦火：优先中空、发光、带花纹
- 体卦土：土石、陶瓷、收纳、块状
- 体卦金：坚硬金石金属；乾金实心，兑金带口缺口
- 体卦水：液体、潮湿、隐伏软体

> 例子：上一局天雷无妄【体乾金】，第一步直接锁定：**坚硬实心类，金石干果硬壳，优先排除中空电器**，就不容易误判音响。

### 技巧 2：五行生克，用来判断新旧、完好程度（不是猜物品名字）

射覆中生克不主吉凶，看物品状态：

- 体得生：东西完好、饱满、崭新；
- 体受克：破损、残缺、老旧、开裂；
- 体比和：完好，本色，结实。

例：体乾金，用震木 → 木克金，物品外表会有纹路、划痕、外壳有裂纹（核桃壳纹路就是震木克乾金）。

### 技巧 3：五行旺衰，修正象的强弱（梅花射覆）

按问卦当下季节看：

- 春木旺：木类象力量强，草木、纸张优先；金衰，金属类可能性降低
- 夏火旺：火象（中空、发光）力量大
- 秋金旺：金石硬圆之物优先
- 冬水旺：液体、含水物品优先
- 四季末土旺：土石陶瓷优先

> 旺衰只调整**可能性权重**，不是死标准。比如秋天照样可以出现木类物品，只是概率低一点。

### 技巧 4：五行 + 八卦组合取象（最实用，射覆必用）

五行定材质，八卦定形态功能，两两搭配：

- 乾金：实心、圆、硬、完整
- 兑金：硬，带缺口开口、出声
- 震木：木类，直立、敲击有声、震动
- 巽木：木 / 纤维，薄片、细长、可摇摆
- 坎水：含水、内实外陷、幽暗弯曲
- 离火：中空、外壳、花纹光亮
- 艮土：硬土石块、凸起疙瘩、阻隔
- 坤土：软土、包容、扁平收纳

## 三、五行取覆避坑清单（高频踩坑点）

1. ❌ 金 = 一定是金属 ✅ 乾兑金五行，可以是玉石、坚硬干果壳（核桃壳五行归金，外壳坚硬收敛），不一定是金属。
2. ❌ 木 = 一定是活植物 ✅ 木五行核心是纤维，纸、布、干果壳都属木。
3. ❌ 离火 = 一定是火、电灯 ✅ 离核心是**中空外壳、有纹路**，镯子、蛋壳都属离。
4. ❌ 坎水 = 一定是液态水 ✅ 坎是润、隐伏，药丸、油脂、潮湿物品都算水五行。
5. ❌ 土 = 只有泥土 ✅ 陶瓷、石头、块状硬物都属土。

## 四、极简速记口诀

> 木曲直，长条纹纤；火炎上，中空文鲜 土稼穑，块厚收纳；金从革，硬圆口缺 水润下，隐曲湿藏；先分五行，再辨卦象

## 五、实操简易流程（射覆套公式）

1. 看**体卦五行** → 锁定材质大类
2. 体卦八卦 → 定本体外形特征
3. 用卦五行 + 卦 → 外在、功用
4. 互卦五行 + 卦 → 内部隐藏结构
5. 变卦五行 + 卦 → 使用变化、破损特征
6. 旺衰微调优先级，排除明显不符合的物品
