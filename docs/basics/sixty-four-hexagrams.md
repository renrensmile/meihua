# 六十四卦基础框架

六十四卦记忆刷题工具中整理了一套可直接用于训练的基础数据：每卦包含**卦名、上卦、下卦**；另一版还补充了卦符号和六爻画。

## 先理解，再记忆

六十四卦由上下两个八卦相重而成。记忆按以下顺序建立关联：

1. **先识八卦**：乾、兑、离、震、巽、坎、艮、坤。
2. **再辨上下**：卦名中的前一象通常对应上卦，后一象对应下卦，例如“天风姤”为上乾下巽。
3. **最后看卦画**：由上而下看六爻时，注意最下方为初爻。

::: tip 数据约定
单卦三爻在数据中按“初爻 → 二爻 → 三爻”的顺序保存；页面展示时反转为“上爻 → 初爻”。这个约定已保留在刷题工具中。
:::

## 练习方式

- 按宫位分组：一次只记八卦，减少记忆负担。
- 正向训练：看到卦名，说出上下卦。
- 反向训练：看到卦画或上下卦，说出卦名。
- 错题复盘：记录混淆的卦，优先回顾易错项。
