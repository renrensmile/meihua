# 基础体系

学习梅花易数，先从象数的基础框架开始。

## 学习顺序

1. 阴阳：理解对立、变化与相对关系。
2. 五行：掌握生、克、乘、侮等基本关系。
3. 八卦：熟悉卦象、卦性、方位、人物、物象等取象线索。
4. 六十四卦：建立卦名、上下卦、卦画与卦序之间的对应关系。
5. 体用：在具体问题中辨别主客与轻重。
