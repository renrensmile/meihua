# 学习工具

这里保留辅助学习与复习的工具，并从笔记正文中建立入口。

## 六十四卦记忆刷题

### [完整版刷题工具](/tools/quiz.html)

- 三种刷题模式：卦名猜上下卦、卦画猜卦名、爻画猜卦名。
- 三类题库：全部卦、已掌握复习、易错题复习。
- 掌握标记、正确率统计、数据导出与导入。

### [经典版刷题工具](/tools/classic-quiz.html)

- 三种刷题模式：卦名猜上下卦、卦符号猜卦名、爻画猜卦名。
- 显示已掌握列表与易错题列表。
- 保留六十四卦 Unicode 卦符号。

::: tip 数据说明
两个工具页各自使用浏览器本地存储保存学习记录，互不共享。换浏览器或清理网站数据前，完整版可先导出备份 JSON。
:::
